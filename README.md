# Matrix

Калькулятор разреженных матриц с графическим интерфейсом на WPF (.NET 7, C#).

Матрица хранится в компактном виде: в связной структуре (узлы со ссылками `Right`/`Down`) лежат только элементы, отличные от повторяющегося значения `V`.

Что есть в коде (`WpfApp1/Filling_Matrix.cs`, `WpfApp1/Additionnsl_Operations.cs`):

- заполнение матрицы вручную, случайными значениями или из файла;
- сложение, вычитание и умножение матриц (перегруженные операторы `+`, `-`, `*`);
- редактирование элементов и поиск физического расположения элемента в памяти;
- сохранение матрицы в файл.

В проекте используется контрол `APE.WPF.Controls.DynamicGrid` для отображения матриц (подключён как отдельный проект).

## Сборка

Нужны Windows и .NET 7 SDK (или Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET»).

```bash
dotnet build WpfApp1.sln
```

Либо откройте `WpfApp1.sln` в Visual Studio и запустите проект `WpfApp1`.
